📦 FITS 文件详解

Coadd 文件 (coadd-<petal>-<tile>-thru<night>.fits)

包含共加光谱 (coadded spectra) 和光纤元数据。每个文件约 52 MB。
字段说明
SIMPLEFITS 标准标志 = T
BITPIX数据类型 = 8
EXTEND包含扩展 = T
SPGRP光谱分组 = 'cumulative'
SPGRPVAL / NIGHT观测夜 = YYYYMMDD
TILEIDDESI 天区 Tile ID
SPECTRO / PETAL光谱仪编号 (0–9)
DEPNAM00-04生成软件栈: python 3.10.14, numpy 1.22.4, scipy 1.8.1, astropy 6.0.1, yaml

关键 HDU: FIBERMAP (目标表), B_WAVELENGTH (波长网格), B_FLUX (B通道流量), R_FLUX, Z_FLUX (R/Z通道), IVAR (逆方差) 等

Redrock 文件 (redrock-<petal>-<tile>-thru<night>.fits)

包含 Redrock 红移拟合结果和目标分类。每个文件约 492 MB (远大于 coadd，因含全部模板拟合详情)。
字段说明
RRVERRedrock 版本 = 0.20.2
TEMNAM00 / TEMFIL00GALAXY 模板 v2.6
TEMNAM01 / TEMFIL01QSO:::LOZ 模板 v1.0 (低红移 QSO)
TEMNAM02 / TEMFIL02QSO:::HIZ 模板 v1.1 (高红移 QSO)

关键 HDU: REDSHIFTS (红移表: Z, ZERR, ZWARN, 目标类型, χ²), FIBERMAP (光纤分配), TSNE2 (t-SNE 二维嵌入)

🔬 红移灾难 (Redshift Catastrophe) 科学背景

问题本质

在 DESI 等宇宙学巡天中，Redrock 使用模板拟合 (template fitting) 确定光谱红移。错误拟合可能发生:

  • 天光线污染：高流量的 airglow 谱线被误匹配为天体谱线
  • χ² 局部极小：错误匹配在竞争中胜出，产生错误红移

验证方法

同一光源的重复曝光是核心验证策略:

曝光 A → Redrock → 红移 Z₁
vs
曝光 B → Redrock → 红移 Z₂

✅ |Z₁ − Z₂| 很小 → 红移可信
❌ |Z₁ − Z₂| 很大 → 疑似红移灾难

科学影响

红移灾难引入的偏差会被传播到:

  • BAO (重子声学振荡) 测量 → 暗能量约束偏移
  • LSS (大尺度结构) 演化研究 → 宇宙学参数系统性偏差
