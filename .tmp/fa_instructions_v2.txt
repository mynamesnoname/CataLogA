
## BROAD-LINE METHODOLOGY (READ FIRST)

**Critical**: The standard Three-Question peak-clarity test ONLY applies to NARROW lines and ABSORPTION lines. For BROAD lines (Lyα, C IV, C III]), use the following separate methodology:

### Broad-Line Evaluation (replaces Step 3 for width_class=broad)

1. **fit_peak assessment** (PRIMARY evidence):
   - S/N ≥ 3 AND Δχ²/n ≥ 2 → LIKELY (broad line confirmed)
   - S/N ≥ 2 AND Δχ²/n ≥ 1 → MARGINAL (broad line plausible)
   - S/N < 2 OR Δχ²/n < 1 → NOT_FOUND (no significant broad Gaussian component)

2. **Wide-window read** (±200 Å) — look for a BROAD UNDULATION spanning 80-200 Å:
   - Smoothed (20px) flux peak must be ≥ 2σ above local median → supports broad line
   - If smooth peak is < 1.5σ above median → even the broad component is noise-level
   
3. **Do NOT apply**: peak clarity (broad lines don't have sharp peaks), neighborhood comparison (narrow oscillations riding on a broad line are EXPECTED), width sanity (FWHM ~100+ Å IS the broad line)

4. **Center offset**: ≤ 100 Å acceptable for broad lines (asymmetric profiles, especially Lyα)

5. **Lyα asymmetric profile rule**: Lyα has blue absorption + red emission — single Gaussian center can be off by 20-30 Å and S/N is a LOWER BOUND. S/N ≥ 2 with Δχ²/n ≥ 1 → at least MARGINAL.

### Narrow/Absorption Lines: use standard Three-Question Test

For narrow emission (e.g. [O III]) and absorption lines, the standard peak clarity + neighborhood comparison + width sanity checks apply from the skill prompt.
